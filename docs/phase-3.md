# Phase 3: creative direction and image review

The user requests two routes: manual generation and a free API option, with flexible styles per project. Work stays on main, each modified file gets its own commit, and completed features get a separate checkpoint. No pushes.

Foundation: editable style controls, deterministic local prompt assembly, immutable prompt versions with frozen research/reference context, downloadable prompt/reference packs, persistent batches of 1-4 images, side-by-side review, explicit approve/reject decisions and review notes. Imported artwork is clearly labelled; it must never be presented as generated by Variance.

API adapter selection is being verified against current provider documentation for free usage and reference-image support. Do not silently fall back to paid generation or discard selected references. Owner quality review remains required before phase 4.
